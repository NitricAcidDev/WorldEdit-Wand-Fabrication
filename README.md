# WorldEdit Wand Fabrication

By NitricAcid. Automatically restores your [WorldEdit Items](https://modrinth.com/mod/worldedit-items) Wand Axe in creative mode.

This works like [Create: Creative Tools Fabrications](https://github.com/NitricAcidDev/Create-Extra-Stuff/tree/main/create-creative-tools-fabrications), but restores the Wand Axe instead of the Create wrench. Requires WorldEdit Items. The existing inventory handling is preserved. Enable or disable restoration with the single `enabled` setting in `config/worldeditwandfabrication-client.toml`. Builds write jars to `build/libs` and do not install them into a game profile automatically.
