# WorldEdit Wand Fabrication

### A simple mod that lets you keep your [WorldEdit Items](https://modrinth.com/mod/worldedit-items) Wand Axe when clearing your inventory in creative mode, like [Create: Creative Tools Fabrications](https://github.com/NitricAcidDev/Create-Extra-Stuff/tree/main/create-creative-tools-fabrications) does for Create tools.
