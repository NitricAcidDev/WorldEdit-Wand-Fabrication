# WorldEdit Wand Fabrication

By NitricAcid. Automatically restores your [WorldEdit Items](https://modrinth.com/mod/worldedit-items) Wand Axe in creative mode.

The existing inventory handling from [Create: Creative Tools Fabrications](https://github.com/NitricAcidDev/Create-Extra-Stuff/tree/main/create-creative-tools-fabrications) is preserved. Configure Wand Axe restoration with the single `enabled` setting in `config/worldeditwandfabrication-client.toml`. Builds write jars to `build/libs` and do not install them into a game profile automatically.
